PII NER 모델에서 ORG 오탐이 가장 큰 골치였다. "다음 주에 회의" 같은 평범한 문장에서 "다음" 을 ORG 로 잡거나, 파일경로의 영문 prefix "OG_네비웍스" 를 회사명으로 잡거나, "딥페이크 영상" 의 "딥페이크" 를 조직명으로 잡는 식이었다. 이 글은 그 오탐을 줄이려고 만든 419 sample 보강 학습이 어떻게 역효과를 냈는지, 그리고 같은 문제를 학습 대신 규칙·정책으로 풀었을 때 어떻게 달라졌는지를 정리한다.

## 발단 — 419 sample 의 의도

기존 학습 데이터에서 본 ORG 오탐 패턴을 정리해 보면 세 갈래였다.

- **일반어 동음이의**: "다음·딥페이크·키로거·모의침투·창업지원·은행·WEB·BTC·IOC" 같이, 같은 단어가 회사명일 때도 있고 일반 명사일 때도 있다.
- **영문 식별자**: 파일경로 안에서 등장하는 "OG_*·malware_*·CoreRND·deepfake" 같은 영문 prefix.
- **부서명**: "AI인증개발팀·옴니원개발팀" 같은 자사 부서. 우리 정책상 이건 ORG 인정.

이걸 각각 합성 데이터로 만들었다.

- 일반어 negative: "다음 주에 회의" / "딥페이크 영상이 늘어나고 있다" — 79 sample, `spans=[]`
- 식별자 negative + boundary: "OG_네비웍스 로그 확인" — 회사명 부분만 ORG 라벨, 20 + 80 sample
- 부서명 positive: "기반기술팀 회의 일정 공유" — 240 sample, ORG positive

합쳐 419 sample. 기존 학습셋 79K 에 더해 koelectra 를 재학습.

## 결과 — docx 2,242 paragraph 평가

평가는 사내 문서 docx 한 본을 BERT + regex hybrid 로 돌리고, 카테고리별 추출량을 이전과 비교했다.

| 카테고리 | 이전 koelectra | 419 sample 보강 후 | 증감 |
|---|---|---|---|
| ORG | 198 | 227 | +29 (+14.6%) |
| NAME | 56 | 60 | +4 |
| ADDRESS | 10 | 9 | -1 |
| ACCOUNT | 4 | 4 | ─ |
| **총** | **268** | **300** | **+32 (+12%)** |

오탐을 줄이려고 보강했는데 오히려 12 % 늘었다. 사라진 span 과 새로 생긴 span 을 따로 보면 양쪽 효과가 다 있었다.

**의도한 효과 — 사라진 오탐**

- "딥페이크" ORG 사라짐
- "WEB" ORG 사라짐
- "OG"·"OG_네비웍스"·"OG_ABL생명" 식별자 boundary 모두 해결

여기까지는 합성 데이터의 직접적 학습이 작동했다. "이 단어는 ORG 가 아니다" 를 본 데로 답했다.

**부작용 — 진짜 ORG 가 사라짐**

- 한국수자원공사
- 한국광해관리공단
- 한국문화관광연구원

위키·정부 사이트에 등록된 명백한 공공기관이 ORG 라벨에서 빠졌다. 마스킹이 안 되는 쪽으로 빠졌다는 뜻이다.

**새 오탐도 생김**

- "말뭉치" 가 ORG 로 (10번 이상 반복 등장)
- "기준일" 이 NAME 으로
- "유 (1)" 이 ORG 로

학습 전에 없던 오탐이 새로 생겼다. 분포 어딘가가 흔들린 결과다.

## 왜 이런 일이 벌어졌나

학습 데이터 419 의 내부 비율을 다시 보자.

```
부서명 positive (ORG=O):     240  (57 %)
식별자 boundary (회사명만 ORG): 80  (19 %)
일반어 negative (ORG=[]):       79  (19 %)
식별자 직접 negative:           20  (5 %)
```

부서명 positive 가 절반을 넘는다. 그리고 부서명은 거의 모두 "○○○○팀" 패턴이다. 모델이 "부서명 = ORG positive" 를 학습하면 그 분포에서 가장 자주 본 패턴, 즉 **짧은 한글 단어 + 접미사 + ORG 라벨** 이 강화된다.

이게 mis-generalization 으로 이어진다. "말뭉치"·"기준일"·"유 (1)" 도 짧은 한글 + 접미사스러운 형태고, 학습된 패턴과 닮았다. 모델은 분포에서 본 모양을 일반화한 결과 비슷한 형태를 ORG 로 쏟아낸다.

반대로 진짜 ORG (한국수자원공사·한국문화관광연구원) 는 길고 복합명사적이다. 강화된 패턴 (짧고 단순한 prefix + 접미사) 과 모양이 달라 우선순위가 떨어진다.

여기에 또 다른 변수가 겹쳤다. **일반어 negative 79 sample 이 잡은 단어는 21개뿐**이다. "다음·딥페이크·키로거" 같은 직접 본 단어는 negative 학습이 강하게 들어갔지만, 학습 데이터 분포 바깥의 일반어 (예: "근거·여기·쪽·말뭉치") 에는 negative 시그널이 없다. 그러니 그쪽으로 일반화는 잘 안 됐다.

결국 419 sample 은 좁고 편향됐다. 좁은 의도 (특정 단어 21개) 와 큰 비중 (부서명 240) 이 같이 있으면, 모델은 비중 쪽으로 끌려간다.

## 학습 회귀의 또 다른 면 — 학습 손실 그래프

회귀는 평가 metric 뿐 아니라 학습 손실 자체에서도 보였다.

| epoch | train loss | val F1 | hard F1 | best? |
|---|---|---|---|---|
| 1 | 10.41 | 0.991 | 0.867 | ★ |
| 2 | 0.50 | 0.995 | 0.896 | ★ |
| 5 | **0.18** | **0.996** | **0.897** | **★★** |
| 6 | 0.14 | — | — | (수렴) |
| 8 | **2.53** | 0.716 | 0.612 | ❌ |

best 는 에포크 5 에서 멈췄고, 그 뒤로는 학습 손실이 0.14 → 2.53 으로 폭증했다. CRF + cosine LR decay 의 후반 instability 로 보이는데, 핵심은 best 모델이 회귀 전 epoch 의 가중치라는 점이다. 즉 위에서 본 docx 결과는 가장 좋았던 epoch 의 모델에서 나온 결과지, 회귀한 모델의 결과가 아니다. 그 best 시점에서도 이미 의도와 다른 방향의 일반화가 일어났다는 뜻.

## 결정 — 학습 대신 정책 + 규칙

여기서 두 갈래 길이 있었다.

1. 학습 데이터를 더 크게·균형 있게 다시 만들어 재학습
2. 정책을 명확히 하고, 그 정책이 규칙으로 표현 가능한 부분은 규칙으로 처리

후자를 택했다. 이유는 단순하다. **모델 학습은 분포를 옮기는 일이고, 분포를 옮기면 의도 외의 변화도 같이 따라온다.** 우리가 ORG 오탐을 줄이려고 추가한 데이터 419 가, 실제로는 의도 외의 분포까지 끌고 들어왔다는 게 위 사례다.

규칙 (regex) 으로 처리할 수 있는 부분은 규칙이 더 안정적이다. 모델은 보지 못한 단어로 일반화하지만, 규칙은 명시한 범위에서만 동작한다. 일반화의 양면 — 양성으로도 가지만 음성으로도 간다 — 을 회피할 수 있다.

## 정책 v3 — 이름 단독은 PII 가 아니다

정책 변경의 첫 줄은 NAME 이다.

기존 정책에서는 인명을 마스킹 대상으로 봤다. 그런데 실제 운영을 보면 "김철수" 라는 이름 자체로는 누구인지 식별이 안 된다. 위키 등재 공인이 김철수일 수도, 일반 사인이 김철수일 수도 있고, 동명이인 문제 때문에 단독 NAME 마스킹은 보호 가치가 낮다. 정작 PII 로서 의미가 생기는 건 NAME 이 **다른 식별 정보와 결합될 때** 다. "김철수 010-1234-5678" 또는 "김철수 사번 12345 내부 보고서" 같은 컨텍스트.

그래서 정책 v3 의 NAME 룰은 다음과 같다.

- 단독 NAME: 마스킹 X (PII 아님)
- 정형 PII (전화·이메일·계좌 등) 와 결합: 둘 다 마스킹
- 사적 영역 (자택·가족·신상) 결합: NAME 마스킹

ORG 도 마찬가지로 보수적 방향으로 갔다.

- DART 상장사·글로벌 빅테크 사명의 단순 신원 (예: "삼성전자가 발표했다"): 마스킹 X
- 회사 + 내부 정보 결합 (사번·임직원 명단): 내부 정보 마스킹
- 명확한 ORG 접미사 (위원회·진흥원·공단·재단·학회·박물관·도서관·미술관·연합회·연구원·연구소): regex 가 잡아 마스킹
- 모호한 일반어: 마스킹 X

## regex 강화 — 명확한 패턴 12종 추가

정책에서 "보수적" 의 의미를 구체화하면, 모델이 무리해서 추론하지 않게 하는 대신 **확실한 패턴만 규칙으로 잡는다** 가 된다. 한국어 ORG 의 경우 접미사가 명확한 신호다.

regex 에 12종을 추가했다.

```
위원회 · 진흥원 · 공단 · 공사 · 재단(법인) · 학회
박물관 · 도서관 · 미술관 · 연합회 · 연구원 · 연구소
```

룰은 한 줄이다.

```
(?<![가-힣])[가-힣]{2,12}{suffix}(?!장)
```

앞에 한글이 없을 때 (조사·결합 분리), 한글 2~12자 prefix 뒤에 접미사가 붙고, 뒤에 "장" 이 오지 않을 때 (연구원장·연구소장·공사장 같은 직책 제외) 매칭한다.

핵심은 negative lookahead `(?!장)` 이다. `(?![가-힣])` 처럼 한글 전체를 부정하면 조사 (의·가·이·는) 까지 막혀서 "한국문화관광연구원의 보고서" 매칭이 안 된다. `(?!장)` 으로 좁히면 직책만 회피하고 조사는 통과한다.

21개 케이스 테스트는 다음 형태로 정리했다.

```
✓  한국수자원공사가 댐을 관리한다              → ORG: 한국수자원공사
✓  한국문화관광연구원의 보고서                 → ORG: 한국문화관광연구원
✓  방송통신위원회 회의 결과                    → ORG: 방송통신위원회
✓  한국전력공사 본사                          → ORG: 한국전력공사
✓  한국전자통신연구원장이 말했다                → (없음, 직책 회피)
✓  공사장에서 일한다                          → (없음, 직책 회피)
✓  다음 위원회 회의에서                        → (없음, 단독 명사)
✓  박물관에 갔다                              → (없음, 단독 명사)
```

같은 docx 에 새 regex 만 돌리면, 학습 보강으로 사라진 진짜 ORG 3개 (한국수자원공사·한국광해관리공단·한국문화관광연구원) 가 모두 다시 잡혔다. 추가로 신규 ORG 10여 개 (한국인터넷진흥원·국민건강보험공단·한국철도공사·정보통신정책연구원·한국여성정책연구원 등) 가 새로 잡혔다.

요점은 **학습 보강 없이도 ORG TP recall 이 회복**됐다는 거다. 더 정확하게는 회복 + 신규 발견이다. 학습으로 얻으려 했던 효과의 상당 부분을 규칙이 더 안전하게 가져왔다.

## 학습이 필요한 곳은 어디인가

그렇다면 모델 학습은 어디서 의미가 있는가. 규칙이 다루기 어려운 영역에서다.

- **컨텍스트 의존**: 같은 단어가 컨텍스트에 따라 PII 가 되기도 하고 아니기도 하다. "이재용 회장은 누구" (public) vs "이재용 자택 주소" (private).
- **모호한 신규 명칭**: 비상장 스타트업 사명, 외국 회사 약어. 규칙으로 미리 명시할 수 없다.
- **자연 발화 분포**: "다음·여기·근거·구성·포함" 같은 일반어가 ORG/NAME 으로 잘못 잡히지 않도록 하는 학습. 21개 단어로는 부족하고, 200K 수준의 자연 분포가 필요하다.

이 마지막 항목 때문에 우리는 한국어 위키 본문을 학습 데이터로 끌어왔다. 위키 본문은 단순 신원 컨텍스트로 가득하고 (사명·인명·기관명이 풍부하게 등장하지만 결합 PII 는 거의 없다), 분포가 자연스럽다. 이 데이터를 모두 negative 로 라벨해서, "이런 컨텍스트에서는 마스킹 안 함" 을 학습시킬 것이다.

여기서도 함정은 있다. 위키 본문에 우연히 진짜 PII (출판사 전화·연락 이메일 등) 가 섞여 있을 수 있고, 이건 regex 가 잡아서 positive 로 라벨링한다. 그래서 67K 위키 sample 중 0.3 % 만 positive 가 됐고, 99.7 % 는 깨끗한 negative 다.

기존 학습셋 79K + 위키 67K = 146K 가 새 학습셋이다. ORG 시그널은 기존 데이터 (Stage16·Solar 합성·DART boost) 에 충분히 있고, 위키는 모호한 분포에서 "잘못 잡지 않기" 만 가르친다.

## 정리

- 419 같은 작은 보강 데이터는 모델의 분포를 의도 외의 방향으로 끌어갈 위험이 크다. 큰 비중을 차지하는 패턴 (이 경우 부서명 positive 240) 이 mis-generalization 을 일으킨다.
- 규칙으로 표현 가능한 패턴은 규칙이 더 안정적이다. 한국어 ORG 접미사 (위원회·진흥원·공단·재단·학회·박물관·도서관·미술관·연합회·연구원·연구소·공사) 는 충분히 명시 가능한 신호다.
- 모델 학습은 컨텍스트 의존·신규 명칭·자연 발화 분포 같은 "규칙이 다루기 어려운 영역" 에 집중한다. 그리고 그 영역은 작은 sample 로 못 푼다.
- 정책을 먼저 정리하면 어떤 부분이 규칙이고 어떤 부분이 학습인지 갈린다. 정책 없이 데이터부터 만들면 의도 외의 분포 압력이 모델을 흔든다.
