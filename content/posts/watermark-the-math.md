## 이어서

[앞 글](/posts/watermark-invisible-or-durable/)에서 결론만 적었는데, 식으로 봐야 왜 그런지가
보이는 대목이 몇 군데 있다. 특히 **평균을 빼고 상한을 재는 바람에 4배를 초과한 건**은
식을 쪼개보기 전까지 눈에 안 띄었다. 실제로 쓴 것만 모은다.

기호부터. 입력 문장이 인코더를 지나 나오는 은닉 표현이 `h ∈ R^d` (d=768), 분류기 가중치가
`W ∈ R^(C×d)` (C=클래스 수), 로짓이 `z = W h` 다. 판정은 이 `z` 하나로 갈린다.

## 치환이 함수를 보존하는 이유
 치환행렬 `P` 는 직교라 `PᵀP = I` 이고,
활성함수 `σ` 가 원소별이라 `σ(Pu) = P σ(u)` 가 성립한다.

```
W_in  ← P W_in
b_in  ← P b_in
W_out ← W_out Pᵀ

W_out Pᵀ · σ(P W_in x + P b_in)
  = W_out Pᵀ P · σ(W_in x + b_in)
  = W_out σ(W_in x + b_in)          ← 원래 함수와 동일
```

비트는 유닛 쌍의 앞뒤로 읽는다. `pos(u)` 를 치환 후 u 의 자리라 하면

```
b_k = 1[ pos(a_k) < pos(b_k) ]
```

## 저에너지 방향은 SVD 로 찾는다
 문장 n 개의 표현을 쌓은 `H ∈ R^(n×d)`, 평균 `μ` 에 대해

```
H − 1μᵀ = U Σ Vᵀ,     Σ = diag(s₁ ≥ … ≥ s_d)
방향 i 가 담는 에너지 비중 = s_i² / Σⱼ sⱼ²
```

실측에서 상위 10방향이 77.62%, 하위 120방향이 0.030% 였다. 한 가지 함정이 있다 —
`rank(H − 1μᵀ) ≤ min(n,d) − 1` 이라 **마지막 특이값은 구조적으로 0** 이다.
`s₇₆₈ = 1.16e-05` 로 바로 앞 `s₇₆₇ = 0.146` 의 1/12,562 였다. 이걸 모르고
`s₁/s₇₆₈` 를 쓰면 2.2×10⁷ 이라는 과장된 비를 얻는다. 실제는 `s₁/s₇₆₇ = 1,814` 다.

## 변화를 그 부분공간에 가둔다
 하위 m개 방향을 모은 `V_low ∈ R^(d×m)` 에 대해

```
ΔW = A V_lowᵀ,        A ∈ R^(C×m)      자유도 = C·m
Δz(h) = ΔW h = A (V_lowᵀ h)
```

괄호 안이 "이 문장이 그 방향에 얼마나 실렸나"이고, 그게 거의 0 이라 로짓이 안 움직인다.

## 평균을 빼면 편향 이동이 안 보인다
 위 식을 평균과 편차로 쪼개면

```
Δz(h) = A V_lowᵀ μ        ← 모든 문장에 공통 (사실상 편향 이동)
      + A V_lowᵀ (h − μ)  ← 문장마다 다른 부분
```

상한을 **중심화한 H** 로 재면 첫 항이 계산에서 빠진다. 그래서 상한을 지켰다고 믿은 판본의
실제 최대 로짓 변화가 4배 초과였다. 연속학습 문헌이 **비중심화** 공분산을 쓰는 이유가 이것이다.
실측으로도 저에너지 방향에서 변동분은 111배 줄지만 상수분은 6.6배밖에 안 줄었다.

## 크기 상한
 표본 최대 로짓 변화를 δ 로 묶고 배수 s 를 곱한다.

```
κ = min(1, δ / maxᵢ |Δz(hᵢ)|)
ΔW ← κ · s · ΔW
```

## 비트를 심고 읽기
 비밀 행렬 `X ∈ R^(B×Cm)`, 목표 비트 `bₖ`, 부호 `σₖ = 2bₖ − 1` 일 때

```
심기: min_A  Σₖ softplus(1 − σₖ ⟨Xₖ, vec(A)⟩) + λ‖A‖²
읽기: b̂ₖ = 1[ ⟨Xₖ, vec(A)⟩ > 0 ],   A = (W − W₀) V_low
```

부호 기반(방식 1)은 `A` 없이 `b̂ₖ = 1[⟨Xₖ, vec(W)⟩ > 0]` 이라 **원본이 없어도 읽힌다.**
저에너지는 `W₀` 가 필요하고, 치환은 원본 전체가 있어야 순서를 복원한다.

## 글자로 되돌리기
 36심볼이라 글자당 6비트, r중 반복 후 다수결.

```
b̃ⱼ = 1[ Σ_{t<r} b̂_{j+tL} ≥ ⌊r/2⌋+1 ]
c   = ALPHA[ Σ_{i<6} b̃_{6j+i} · 2^(5−i) ]
```

## 신호 대 잡음
 양자화 `Q` 를 걸었을 때 읽는 값이 얼마나 흔들리는가.

```
signal = medianₖ |⟨Xₖ, vec(A)⟩|
noise  = meanₖ   |⟨Xₖ, vec(A_q − A)⟩|,   A_q = (Q(W) − W₀) V_low
```

배수 1 에서 `0.0015` 대 `0.0467` 로 신호가 잡음보다 31배 작았다.
배수를 100 배 올리면 S/N 이 0.03 → 3.3 이 되면서 int4 를 견딘다.

## 뒤집힘을 미리 계산하기
 임계값 근처 문장 밀도를 ρ(점수 1 구간당 문장 수)라 하면

```
E[뒤집힘] ≈ maxᵢ |Δpᵢ| × ρ
```

임계값 ±0.01 안에 200만 중 16건이 있었으니 ρ ≈ 800. 점수 변화를 1e-3 으로 묶으면
기대값이 200만 중 0.8건이다. 실제로 그 판본은 0건이었다.

## 넓게 보면

세 군데가 식으로만 드러났다. **치환 항등식**은 왜 판정이 한 건도 안 바뀌는지를 증명해준다 —
근사가 아니라 등식이다. **평균 분해**는 상한을 어디서 재야 하는지를 알려줬고, 안 쪼갰으면
4배 초과를 계속 몰랐을 것이다. **랭크 결손**은 특이값 비를 인용할 때의 함정이다.

숫자만 보고 결론을 내리면 이 셋 다 놓친다. 특히 두 번째는 코드가 에러 없이 잘 돌고
그럴듯한 값을 냈기 때문에, 식을 다시 쓰기 전까지 아무 신호가 없었다.

## 메모

- 함수 보존을 주장할 땐 항등식으로 확인한다. 치환은 근사가 아니라 정확히 같다.
- 상한을 걸 때 무엇을 기준으로 재는지 본다. 평균을 빼면 편향 이동이 계산에서 빠진다.
- 중심화한 행렬의 마지막 특이값은 구조적으로 0 이다. 조건수나 특이값 비를 인용하기 전에 확인한다.
